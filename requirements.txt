# EduMusic dependencies
#
# IMPORTANT -- aubio does not have prebuilt wheels for macOS arm64, so it
# compiles from source, and version 0.4.9 (the latest release, from 2019)
# does not build cleanly against modern clang or ffmpeg 8. A plain
# `pip install -r requirements.txt` WILL FAIL on aubio.
#
# Install with:
#
#     pip install setuptools wheel
#     CFLAGS="-Wno-error=incompatible-function-pointer-types" \
#     PKG_CONFIG_LIBDIR="" PKG_CONFIG_PATH="" \
#       pip install -r requirements.txt --no-build-isolation
#
# Why each flag is needed:
#   CFLAGS=-Wno-error=...  clang 16+ treats aubio's ufunc function-pointer
#                          mismatch as an error rather than a warning.
#   PKG_CONFIG_LIBDIR=""   hides ffmpeg from aubio's build. aubio 0.4.9 uses
#                          the pre-ffmpeg-5 libav API (AVStream.codec), which
#                          no longer exists. We only read from the microphone
#                          via sounddevice, so aubio's file decoding is unused.
#   --no-build-isolation   lets the build see the setuptools/numpy installed
#                          above instead of a fresh isolated environment.
#
# Verified working: Python 3.14.2, numpy 2.5.3, macOS arm64 (Darwin 25.5).

# Audio I/O (microphone input + metronome playback)
sounddevice>=0.4.6

# Array math for pitch conversion and click synthesis
numpy>=1.24

# Monophonic pitch detection (YIN). See the build notes above.
aubio==0.4.9
